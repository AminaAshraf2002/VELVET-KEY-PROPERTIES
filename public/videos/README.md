# IdentitySection Arrow Videos

Place your 4 MP4 video files in this folder with the following filenames:

1. `arrow-1.mp4` — Background video for Arrow 01
2. `arrow-2.mp4` — Background video for Arrow 02
3. `arrow-3.mp4` — Background video for Arrow 03
4. `arrow-4.mp4` — Background video for Arrow 04

### Recommended Video Specs:
- Format: MP4 (H.264 / AAC)
- Resolution: 720p or 1080p landscape (e.g. 1280x720 or 1920x1080)
- Optimized / compressed for web (e.g., Handbrake or ffmpeg with crf 24-28)
- Silent / muted (audio track will be muted automatically)

*Note: In the meantime, the component gracefully falls back to high-resolution architectural posters (`/estate-slide-1.jpg` ... `/estate-slide-4.jpg`).*
